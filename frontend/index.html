Platform Overview

What the Website Does

PAL-AI combines machine learning, climate trend processing, open-source satellite terrain data, and risk modeling into one farmer-facing web system. Each module focuses on a different decision layer of rice production.

📈

Rice Yield Forecasting

Uses climate variables and machine learning to estimate rice yield and long-range production trends.

🛰️

3D Farm Site Analysis

Converts elevation data into a 3D terrain model with slope, aspect, suitability, and cross-section analysis.

💧

Irrigation and Water Bodies

Detects nearby mapped rivers, streams, reservoirs, ponds, and water features for irrigation planning.

🌱

Soil and Fertilizer Recommendation

Scores fertilizer compatibility using terrain-inferred soil indicators, crop type, and agronomic factors.

🐛

Pest Outbreak Analysis

Simulates pest outbreak vulnerability using Bayesian-style risk scoring, heatmaps, and pest-specific cards.

🛡️

PALADIN Assistant

Provides AI-assisted farming explanations and image-based plant diagnosis support through a chatbot window.

Sow Timely, Grow Primely

This year was the pioneering phase of the project. It first started with only the rice yield forecasting algorithm developed, with no system or website yet. It focused on mathematical models for forecasting using Multiple Linear Regression.
